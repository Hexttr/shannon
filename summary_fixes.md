# Исправления фронтенда

## Проблемы которые были исправлены:

1. **Неправильный base path** - Vite использовал `/app/` вместо `/`
   - Исправлено в `vite.config.ts`: изменен base path на `/`
   - Исправлено в `App.tsx`: убран basename `/app` из BrowserRouter

2. **Пути к assets** - в index.html были пути `/app/assets/` вместо `/assets/`
   - Исправлено автоматически при пересборке с правильным base path

3. **Обработка ошибок** - добавлена обработка ошибок в `main.tsx` для диагностики проблем
