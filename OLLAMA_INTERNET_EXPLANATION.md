# Доступ Ollama к интернету и модели

## 🔍 Анализ ошибок пентеста:

### Проблема НЕ в доступе к интернету!

**Реальная проблема:** Команды не выполнялись из-за ошибки экранирования в SSH клиенте:
- `timeout: failed to run command 'nmap ...': No such file or directory`
- Это означало что команды не находились из-за неправильного экранирования

**Исправлено:** Убрано неправильное экранирование через `bash -c` и `escapeshellarg`

## 📊 Модели Ollama с доступом к интернету:

### ❌ Текущая модель llama3.2:3b:
- **НЕ имеет** прямого доступа к интернету
- **НЕ поддерживает** tool calling (function calling)
- Работает только на основе знаний из обучения

### ✅ Модели с поддержкой интернета:

**1. Модели с Tool Calling:**
- Могут использовать инструменты для доступа к API
- Могут делать HTTP запросы через специальные функции
- Примеры: 
  - `deepseek-r1` - поддерживает tool calling
  - `llama3.1` (некоторые версии) - могут иметь tool calling
  - `qwen2.5` - некоторые версии с tool calling

**2. Как это работает:**
- Модель вызывает специальные функции (tools)
- Эти функции делают HTTP запросы к внешним API
- Результаты возвращаются модели для анализа

**3. Требования:**
- Модель должна поддерживать tool calling
- Нужна настройка внешних API
- Требуется дополнительная конфигурация
